# ✨ TaskFlow — Premium To-Do App

A modern, responsive, and feature-rich **To-Do List web application** built using **HTML, CSS, and JavaScript**. TaskFlow helps users organize daily tasks, set priorities, track progress, and manage productivity through a clean and premium interface.

## 🚀 Features

* ➕ Create new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as completed
* 🔍 Search tasks
* 🎯 Set task priority

  * Low
  * Medium
  * High
* 🏷️ Organize tasks by categories

  * Personal
  * Work
  * Study
  * Shopping
  * Other
* 📅 Add due dates
* ⚠️ Overdue task detection
* 📊 Task statistics dashboard
* 📈 Completion progress tracking
* 🔎 Filter tasks

  * All Tasks
  * Active
  * Completed
  * High Priority
* ↕️ Sort tasks

  * Newest
  * Oldest
  * Priority
  * Due Date
* 🌙 Dark Mode
* ☀️ Light Mode
* 💾 LocalStorage support
* 📱 Fully responsive design
* ✨ Smooth animations and modern glassmorphism UI

## 🛠️ Technologies Used

* **HTML5** — Structure and layout
* **CSS3** — Styling, responsive design, animations, and glassmorphism effects
* **JavaScript** — Application logic, DOM manipulation, events, filtering, sorting, and task management
* **LocalStorage** — Persistent task data storage
* **Google Fonts** — Inter typography

## 💾 Data Storage

TaskFlow uses the browser's **LocalStorage** to store tasks.

This means:

* Tasks remain available after refreshing the page.
* Tasks remain available after closing and reopening the browser.
* No external database is required.
